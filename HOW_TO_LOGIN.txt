================================================================================
                        TROUBLESHOOTING
================================================================================

Problem: "Login Failed" Error
------------------------------
Solution: Make sure you're typing the password EXACTLY as shown:
   - Capital "A" at the start
   - Lowercase "dmin"
   - @ symbol
   - Numbers "123"
   
   Correct: Admin@123


Problem: Nothing Happens When I Click Login
--------------------------------------------
Solution: Check if backend is running
   1. Open new terminal
   2. Go to backend folder: cd backend
   3. Run: php artisan serve
   4. Should see: "Laravel development server started"


Problem: Page Shows Error About API
------------------------------------
Solution: Make sure both servers are running:
   1. Backend: cd backend & php artisan serve (port 8000)
   2. Frontend: cd frontend & npm run dev (port 8001)
